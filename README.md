# Verilog Learning

This will be a  collection of Verilog programs, practice exercises, and simulations documenting my journey of learning Digital Design and RTL development.

This repository will covers fundamental concepts, combinational and sequential circuits, testbenches, and basic SystemVerilog concepts, with a focus on hands-on coding and simulation.

**Goal:** Build a strong foundation in Verilog and digital design before moving on to FPGA implementation and hardware projects.
